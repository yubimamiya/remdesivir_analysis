# Prolonging remdesivir's tri-phosphorylated metabolite half-life rather than parent compound would increase SARS-CoV-2 clearance rate

This repository contains the code and data used for the analysis and figure generation in the scientific paper: **"Prolonging remdesivir's tri-phosphorylated metabolite half-life rather than parent compound would increase SARS-CoV-2 clearance rate"**.

## Repository Contents

The code provided here allows for the reproduction of the simulations and figures presented in the manuscript and its supplementary material. 

Below is the guide mapping each figure from the paper to its corresponding Jupyter notebook:

*   **Fig 1b:** `PKFigures_Publication.ipynb`
*   **Fig 2b, Fig 2c, Supplement Fig 1, Supplement Fig 2:** `ViralDynamicSimulations_Publication.ipynb`
*   **Fig 2d, 2e:** `ViralLoadHalfLife_Publication.ipynb`
*   **Fig 3a, 3b, 3c:** `EfficacyComparison_Publication.ipynb`
*   **Fig 4a, 4b, 4c, 4d, 4e, 4f:** `PKRatesSensitivityAnalysis_Publication.ipynb`
*   **Fig 5a, 5b, 5c, 5d:** `DoseSensitivityAnalysis_Publication.ipynb`
*   **Supplement Fig 3, Supplement Fig 4:** `ParameterVariabilityComparison_Publication.ipynb`

## Usage

1. Download the notebooks and data in this repository to the same directory on local machine.
2. Ensure you have the necessary dependencies installed (NumPy, Pandas, Matplotlib, SciPy). 
3. Run the desired notebook using Jupyter Notebook, JupyterLab, or Google CoLab.
